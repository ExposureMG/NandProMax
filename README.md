# NandProMax

Cross-platform Xbox 360 NAND/eMMC flasher tool.

## Devices

- ESPFlasher (ESP32)
- PicoFlasher v4 TCP - Untested
- PicoFlasher v4 USB - Untested
- LPC (JRP v2, NAND-X, etc) - Untested
- TX DemoN - Untested
- CMSIS-DAP v2
