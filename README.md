# NandProMax

Cross-platform flashing library; The flashers that don't already have flashing libraries.

- PicoFlasher Protocol v4
- LPC (NAND-X, MTX, JRP)
- TX Demon


## Building

Not stable release yet, work it out. its only rust. Or use the runner.
